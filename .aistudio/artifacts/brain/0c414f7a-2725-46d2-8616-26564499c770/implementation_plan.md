# طراحی صفحات اختصاصی برای ۵ حوزه فعالیت استودیو آرتا ماد هنر

این طرح، بخش «حوزه‌های فعالیت و آثار منتخب استودیو» در صفحه اصلی را به یک چیدمان شبکه‌ای (Bento Grid) خلاصه، شیک و خلوت تبدیل می‌کند و برای هر یک از ۵ دپارتمان تخصصی استودیو یک **صفحه اختصاصی کامل** به همراه نوار جابه‌جایی سریع بین حوزه‌ها، گالری آثار و معرفی اعضای متخصص همان دپارتمان ایجاد می‌نماید.

## تصمیمات تاییدشده توسط شما

> [!IMPORTANT]
> بر اساس پاسخ‌های شما، ساختار صفحات اختصاصی و نحوه نمایش در صفحه اصلی به شرح زیر تنظیم شده است:

- **نمایش در صفحه اصلی**: جایگزینی کارت‌های طولانی فعلی با **کارت‌های خلاصه و شبکه‌ای (Bento / Grid)** که با کلیک روی هر کدام، کاربر وارد صفحه اختصاصی آن حوزه می‌شود.
- **محتوای صفحات اختصاصی هر حوزه**:
  1. معرفی جامع دپارتمان، رویکرد هنری/فنی و ویژگی‌های شاخص از کاتالوگ استودیو.
  2. **گالری نمونه‌کارها، تصاویر و ویدیوهای مربوط به آن دپارتمان** (با قابلیت تماشای ویدیو و ورق زدن تصاویر در ابعاد بزرگ).
  3. **معرفی اعضای متخصص همان دپارتمان در استودیو** (کارت‌های خلاصه اعضای مرتبط که با کلیک روی آن‌ها، رزومه و سوابق کاری‌شان باز می‌شود).
- **ناوبری و جابه‌جایی**: قرارگیری **دکمه بازگشت به صفحه اصلی** به همراه **نوار جابه‌جایی سریع بین ۵ حوزه فعالیت** در بالای صفحه اختصاصی (سازگار با GitHub Pages از طریق مدیریت وضعیت و Hash URL).

## ۱. نمای کلی و مفهوم اصلی (Overview & Core Concept)

- **هدف اصلی**: کاهش شلوغی صفحه اصلی وب‌سایت و اختصاص فضای کافی و مستقل به هر یک از ۵ محور فعالیت استودیو آرتا ماد هنر:
  1. **انیمیشن و توسعه IP** (شامل سینمایی بلند «روز شگفت‌انگیز»، «روز شگفت‌انگیز ۲» و «داستان نوروز»)
  2. **تبلیغات، تیزرهای تجاری و تولیدات تصویری CGI**
  3. **بازی‌سازی و سرگرمی تعاملی (PC, Mobile & Tabletop)**
  4. **فناوری‌های نوین، هوش مصنوعی و توسعه محصول (Web3 & AI)**
  5. **تجربه‌های بصری فراگیر، ویدئو مپینگ و رسانه‌های نوین**
- **ارزش کلیدی برای مخاطب**: بازدیدکنندگان، تهیه‌کنندگان و مشتریان تجاری در صفحه اصلی در یک نگاه با ۵ دپارتمان آشنا می‌شوند و با ورود به صفحه هر دپارتمان، مستقیماً نمونه‌کارها و تیم متخصص همان بخش را مشاهده می‌کنند.

## ۲. تجربه کاربری و طراحی بصری (User Experience & Visual Design)

### الف) جریان حرکت کاربر (User Flow)
1. **صفحه اصلی (بخش حوزه‌های فعالیت)**:
   - نمایش ۵ کارت خلاصه در یک گرید متوازن (۲ کارت شاخص در ردیف اول و ۳ کارت در ردیف دوم در نسخه دسکتاپ).
   - هر کارت شامل تصویر/کاور هنری، شماره و عنوان حوزه، توضیح کوتاه دوخطی و دکمه «ورود به صفحه دپارتمان ←» است.
2. **ورود به صفحه اختصاصی حوزه**:
   - با کلیک روی هر کارت، صفحه به نرمی به بالای دید اسکرول شده و نمای صفحه اختصاصی آن حوزه باز می‌شود (همراه با ثبت آدرس مانند `#/domain/animation` برای پشتیبانی از دکمه Back مرورگر و اشتراک‌گذاری لینک در GitHub Pages).
3. **گشت‌وگذار در صفحه اختصاصی**:
   - **نوار بالای صفحه اختصاصی**: شامل دکمه «بازگشت به صفحه اصلی» در سمت راست و نوار تب‌های ۵ حوزه برای جابه‌جایی آنی بین دپارتمان‌ها بدون نیاز به بازگشت به خانه.
   - **بخش اول (Hero & Overview)**: معرفی کامل حوزه، دستاوردها و محورهای تخصصی کاتالوگ.
   - **بخش دوم (گالری آثار، تصاویر و ویدیوها)**: نمایش مدیا، تیزرها، اسلایدها و کانسپت‌های بصری مربوط به آن دپارتمان.
   - **بخش سوم (تیم متخصص دپارتمان)**: نمایش هم‌بنیانگذاران مرتبط و اعضای تخصصی همان دپارتمان با قابلیت کلیک برای مشاهده خلاصه سوابق کاری.

### ب) هویت بصری و پالت رنگی
- حفظ کامل پالت رنگی زبان بصری پویو:
  - پس‌زمینه اصلی: عاجی گرم (`#EDE9DF`) و سطوح کارت‌ها (`#FAF8F4` و `#F4F0E6`).
  - رنگ‌های تأکیدی و تعاملی: سبزآبی تیره (`#3E777A`)، فیروزه‌ای (`#65B7B5`)، آبی آسمانی (`#82B9D8`) و اخرایی گرم (`#D6B16A`).
  - تایپوگرافی: فونت وزیرمتن برای متون فارسی و Outfit / JetBrains Mono برای عناوین انگلیسی و شمارنده‌ها، بدون استفاده از بج‌های کپسولی شلوغ (Zero-Pill Metadata).

## ۳. تصمیمات کلیدی محصول و معماری (Key Decisions & Trade-Offs)

- **تصمیم ۱: مسیریابی مبتنی بر Hash (`#/domain/:id`) برای سازگاری کامل با GitHub Pages**
  - *رویکرد انتخاب‌شده*: استفاده از Hash Routing سبک و بومی در کنار State اصلی برنامه.
  - *دلیل*: از آنجا که سایت روی GitHub Pages (`artamad.ir`) میزبانی می‌شود، استفاده از Hash URL تضمین می‌کند که رفرش کردن صفحه یا استفاده از دکمه‌های Back/Forward مرورگر هیچ‌گاه با خطای 404 مواجه نشود.
- **تصمیم ۲: چیدمان شبکه‌ای (Bento Grid) در صفحه اصلی به جای لیست عمودی بلند**
  - *رویکرد انتخاب‌شده*: چیدمان ۲+۳ در دسکتاپ با کارت‌های خلاصه و ارتفاع یکدست.
  - *دلیل*: اسکرول طولانی صفحه اصلی را به شکل چشمگیری کاهش می‌دهد و زیبایی بصری بین بخش «روز شگفت‌انگیز» و بخش «فلسفه و توانمندی‌های استودیو» را دوچندان می‌کند.

## ۴. معماری فنی و جریان داده (Technical Architecture)

```
┌─────────────────────────────────────────────────────────────────────────┐
│                              App (Root State)                           │
│  • activeDomainId: string | null (همگام با window.location.hash)        │
│  • activeMember: TeamMember | null (مودال رزومه و سوابق کاری اعضا)      │
└───────────────────┬─────────────────────────────────┬───────────────────┘
                    │                                 │
      [activeDomainId === null]         [activeDomainId !== null]
                    ▼                                 ▼
┌───────────────────────────────────────┐ ┌───────────────────────────────┐
│        نمای صفحه اصلی استودیو         │ │   صفحه اختصاصی حوزه فعالیت    │
│  • HeroSection                        │ │      (DomainDetailPage)       │
│  • FlagshipSpotlight (روز شگفت‌انگیز) │ ├───────────────────────────────┤
│  • InteractiveShowcase (Bento Grid)   │ │ ۱. نوار بازگشت به خانه +      │
│    └─ ۵ کارت خلاصه دپارتمان‌ها        │ │    سوییچر سریع بین ۵ حوزه     │
│  • EditorialPhilosophy                │ │ ۲. معرفی جامع و محورهای حوزه  │
│  • TeamGallery                        │ │ ۳. گالری نمونه‌کارها، ویدیو   │
│  • IdentityStory                      │ │    و تصاویر اختصاصی دپارتمان  │
└───────────────────────────────────────┘ │ ۴. کارت‌های اعضای متخصص       │
                                          │    همین دپارتمان (قابل کلیک)  │
                                          └───────────────────────────────┘
```

### نگاشت داده‌ها و تعاملات (Interactive State Mapping)
- **داده‌های غنی هر دپارتمان**: هر یک از ۵ حوزه در ساختار داده دارای فهرست آثار و مدیا (ویدیو، اسلایدها یا بوم‌های بصری تعاملی) و همچنین نگاشت به اعضای متخصص همان دپارتمان خواهد بود.
- **تعامل کارت‌های اعضا در صفحه دپارتمان**: کلیک روی کارت هر عضو در پایین صفحه اختصاصی دپارتمان، دقیقاً همان مودال `TeamMemberModal` حاوی «خلاصه سوابق کاری» و معرفی کامل را باز می‌کند.
