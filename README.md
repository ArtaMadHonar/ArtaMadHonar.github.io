# وب‌سایت رسمی استودیو آرتا ماد هنر (Arta Mad Honar Studio)

این پروژه، نسخه بازسازی‌شده، مدرن و کاملاً استاندارد وب‌سایت **استودیو آرتا ماد هنر** است که با فریم‌ورک فوق‌سریع **Astro 5 + React 19 + Tailwind CSS v4** طراحی و بازنویسی شده است.

---

## ۱. نحوه اجرای پروژه روی سیستم شما (Local Host)

خیلی ساده! شما به دو روش می‌توانید وب‌سایت را روی سیستم خودتان بالا بیاورید و بررسی کنید:

### روش اول (سریع‌ترین - بدون نیاز به کدنویسی):
فقط کافی است روی فایل **`run-local.bat`** در پوشه `artamad-studio` دو بار کلیک کنید. یک پنجره مشکی باز می‌شود و سایت را اجرا می‌کند. سپس مرورگر خود را باز کنید و وارد آدرس زیر شوید:
👉 **`http://localhost:3000`**

### روش دوم (از طریق ترمینال):
```bash
cd artamad-studio
npm run dev
```

## ۲. ساختار صفحات وب‌سایت

تمامی صفحات به صورت **صفحات واقعی (Static HTML)** ساخته شده‌اند که هم در گوگل (SEO) رتبه عالی می‌گیرند و هم بسیار سریع باز می‌شوند:

| آدرس صفحه | عنوان |
|---|---|
| `/` | صفحه اصلی (Hero، تیزر سینمایی، اسلایدشو، ۵ دپارتمان، ارکان راهبردی، تیم و فوتر) |
| `/wonderful-day` | دپارتمان انیمیشن سینمایی و دارایی فکری (پروژه بلند «روز شگفت‌انگیز») |
| `/commercial-cgi` | تیزرها و تبلیغات CGI و خودرو (همراه با هوش مصنوعی و BearStudio) |
| `/vfx-mapping` | دپارتمان ویدئو مپینگ معماری و کارگردانی بصری صحنه |
| `/game-lab` | آزمایشگاه بازی‌سازی، اکوسیستم توکن و کاراکترها |
| `/web3-nft` | دپارتمان وب۳، بلاکچین و کالکشن‌های دیجیتال |
| `/404` | صفحه خطای اختصاصی با طراحی هماهنگ |

## ۳. فرم ثبت درخواست همکاری (تلگرام + ایمیل)

فرم همکاری به صورت پیش‌فرض کاملاً فعال است و دارای کد پیگیری اختصاصی (`AMH-XXXXXX`) و ذخیره‌سازی محلی است. 

هنگامی که خواستید پیام‌ها **مستقیماً به ربات تلگرام و ایمیل شما** ارسال شوند:
1. یک فایل به نام `.env` در پوشه `artamad-studio` بسازید (یا فایل `.env.example` را کپی کرده و به `.env` تغییر نام دهید).
2. مقادیر زیر را در آن وارد کنید:

```env
# دریافت پیام در تلگرام:
PUBLIC_TELEGRAM_BOT_TOKEN="توکن_ربات_تلگرام_از_BotFather"
PUBLIC_TELEGRAM_CHAT_ID="شناسه_عددی_اکانت_شما"

# دریافت پیام در ایمیل:
PUBLIC_WEB3FORMS_ACCESS_KEY="کلید_رایگان_از_web3forms.com"
```

## ۴. ویژگی‌های برجسته فنی پروژه

- **۱۰۰٪ مستقل و خودکفا:** تمامی تصاویر و تامبنیل‌های ۳earstudio و کانسپت‌آرت‌ها به صورت فایل محلی در پروژه ذخیره شده‌اند و هیچ وابستگی به هاست‌های متفرقه وجود ندارد.
- **فونت‌های کاملاً لوکال:** فونت فارسی وزیرمتن و فونت انگلیسی Plus Jakarta Sans از داخل سرور پروژه بارگذاری می‌شوند و هیچ اتکایی به Google Fonts (که در ایران کند یا مسدود است) ندارند.
- **سیستم حالت روز و شب (Light / Dark Mode):** با پالت معماری ابسیدین و فیروزه‌ای، با حفظ تم در حافظه مرورگر و بدون هیچ‌گونه پرش رنگ (Zero FOUT).
- **امنیت کامل:** تمام فایل‌های حساس و بلااستفاده (مانند رزومه PDF، فایل‌های تمپ AI Studio و اسکرین‌شات‌ها) از شاخه عمومی حذف شده‌اند.
- **کنترل نسخه گیت (Git):** پروژه دارای مخزن گیت تمیز و مستقل است.
- **انتشار خودکار (GitHub Actions):** فایل آماده در مسیر `.github/workflows/deploy.yml` قرار دارد که با هر تغییر، سایت را به صورت خودکار بیلد و منتشر می‌کند.
